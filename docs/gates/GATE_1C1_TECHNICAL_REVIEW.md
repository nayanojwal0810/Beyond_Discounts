## 2. Defects corrected in this branch

### 2.1 Preserve raw p-values through multiple-testing correction

Previously, `evaluate_external_validation()` rounded a Kruskal–Wallis p-value to six decimal places before `apply_multiple_testing_corrections()` read it. Very small p-values could therefore become literal zero before Holm or Bonferroni adjustment. The computation now retains the raw floating-point p-value and rounds only presentation metrics elsewhere. The interpretation string uses scientific notation for small adjusted p-values.

A small adjusted p-value for Spec B's QA47 result is still **construct-defining**, because QA47 itself is an input to Spec B. It must not be presented as independent evidence of a discovered segment.

### 2.2 Separate failed resamples from low ARI

Previously, an exception during a subsampling run was silently converted into ARI = 0.0. That conflated a failed calculation with an observed unstable partition. The revised function:
- records each seed's success/failure, ARI when measured, and concise error metadata;
- excludes failed runs from ARI summaries rather than fabricating a score;
- reports successful and failed run counts separately; and
- returns `INCOMPLETE` when any scheduled resample fails, or `FAILED` if none succeeds.

The experiment now writes `reports/segmentation/stability_runs.csv` with one aggregate diagnostic row per resample. It must contain no respondent IDs or sampled row indices.

### 2.3 Avoid interpreting a non-significant test as equivalence

A non-significant test does not prove clusters are homogeneous. The report wording generated by the revised code now states that statistically detectable divergence was not found after correction and explicitly avoids an equivalence claim.

### 2.4 Regression coverage added

New tests cover:
- run-level ARIs reproducing the stability summary;
- a simulated failed resample remaining missing rather than being recorded as ARI zero; and
- small positive raw p-values remaining positive through Holm/Bonferroni adjustment.

These tests have been committed to this branch but **have not been executed in the user's local data environment by the Principal Project Lead**. A passing commit is not claimed until the tests and end-to-end run are reproduced.

## 3. Evidence constraining the segmentation claim

The previously committed experiment summary reports:
- Spec A, PAM, k=4 mean silhouette approximately 0.050 and 20.20% negative silhouettes.
- Spec A, PAM, k=4 median subsampling ARI 0.6787, with 8/20 runs below ARI 0.50.
- Spec A, PAM, k=4 mean QA47 scores of 3.440, 3.438, 3.458 and 3.447 across the four clusters; the reported Kruskal–Wallis p-value is approximately 0.998 before correction.
- Spec A k=4 does not show a corrected statistically significant QA46 difference in the committed summary.
- HAC average linkage produces highly unbalanced/chained clusters; HAC complete linkage has weak silhouette performance.

These figures are the **currently committed results**, not a new run independently reproduced during this review. They are sufficient to reject any current claim that four crisp, behaviorally separated, retention-actionable personas have been established. They are not proof that every possible partition is impossible.

## 5. Methodological guardrails

- Use **current-user cohort**, not “active customer,” as the report label. The current-user group is questionnaire-defined and includes a lowest-frequency category; the label does not imply recent transactions or high engagement.
- QA47 is **stated intention to continue at the same frequency if discounts/promotions are reduced**. It is not observed price elasticity, churn probability, retention, or causal sensitivity to a pricing change.
- QA46 is **stated future-use intention**, not observed future behavior.
- QA48 records stated reasons for current non-use. It does not establish why a previous user stopped ordering.
- QA49 is the respondent's one preferred improvement, not a tested intervention response.
- Historical use of multiple apps is not app loyalty or promiscuity; label it **historical platform-repertoire breadth**.
- A failure to reject a difference is not evidence of equivalence. Report sample sizes, effect sizes and uncertainty intervals alongside p-values.
- The survey is cross-sectional, self-reported, category-level and not established as nationally representative. Do not claim a specific firm's customer churn, true CLV, actual repeat purchasing, or causal retention uplift.
